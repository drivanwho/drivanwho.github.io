# 胡逸凡 · Yifan Hu

个人学术主页与写作档案。

- 顶部导航：首页、简历、研究、生活、联系方式；独立生活及联系页面
- 24 篇文集，支持搜索、时间排序和独立阅读
- English / 한국어 / 日本語全文自动翻译入口（Google Translate）
- 暖白、海军蓝与陶土色配色，自然彩色头像，桌面与移动端适配

网站使用预生成 HTML，GitHub Pages 从 main 根目录发布，保留 .nojekyll。

重新生成：运行 `python3 _src/build.py`，再将 `_src/dist/` 内容同步到仓库根目录。文章数据位于 `_src/content/posts.json`。
